# 制作手工试点交接卡

由 AI 从实际材料填写，人只确认自己负责的内容。缺失写“未知/未收到”，不补造通过。此模板不自动运行检查或授权投入。

## 对象与目的

- 项目、任务授权原话/来源、允许修改范围：
- 原稿/候选的版本、路径、摘要与精确集场：
- 粗搭实际对应版本：未知时保持未知。
- 本次想改变的制作决定；需要保住的剧情/情绪功能：
- 资料状态：offline_prepared / human_trial_in_progress / human_trial_recorded。
- 实际参与者及其责任；未到位岗位：

同一预约不重复计数；剩余容量不再次扣除历史消耗。动态条件放行/开工前复核。

## 实读与试镜（真实执行后填写）

- 试前：接受标准、尝试/工时/费用上限、停止条件、确认人、另行费用授权；无授权不执行付费试镜。
- 实读：执行人、日期、版本、范围、实测读演时长、未覆盖动作；不等同成片时长。
- 试镜：全部尝试ID、条件、可用数量、总尝试数、总工时/费用、失败原因与条件变化。
- 推广依据：适用/不适用范围、后续资源预测、仍未知项；一次成功不代表稳定复制。

## 结论与推进条件

- 可做的下一动作、暂缓范围、具体原因：
- 已保留/新发现的制作问题、误拦截、交接及文书工时：
- 编剧修订选择、导演实际反馈、资源责任人决定：未收到不填认可。
- 是否有足够依据自动化重复步骤：未有真人反馈时保持未验证。
- 本轮停止/收缩/继续的实际依据：
- 适用性 current / stale / unknown；需要重核的动作另列。
- 真实制作/付费/采用回执：无则明确未执行，不以本卡替代。
