# 可选：夸克素材获取

仅在用户需要新视频且宿主确有浏览器／桌面操作工具时使用；否则用户手动获取后，接续本地素材清单与 mali-story 上传。

优先检查专用连接器是否支持真实操作。没有连接器时，在当前 UI 中按标题搜索用户指定来源；可从 `https://www.pioz.cn` 开始，找到匹配详情，再打开实际提供的 `pan.quark.cn` 分享。核对剧名、版本、演员或集数，存在歧义时让用户选择。

读取当前桌面工具文档，依据实时标签或截图操作。不要硬编码详情 ID、分享 token、窗口坐标或应用深链。登录／验证码留给用户完成。

选择匹配文件夹，使用下载动作进入夸克客户端，在下载对话框中核对目标目录。先查是否已有匹配任务，防止重复提交；“任务准备中”只代表排队。

下载结束需核对已完成任务和实际文件，包括集序、数量与可读性。标题中的“80 集”不保证恰好 80 个文件，补充资料可能混在一起。素材保存在用户项目之外或其指定目录，不能存进技能安装目录。

分享失效、交接失败或无桌面权限时报告实际状态并允许手动接续。不自动购买会员、改变代理设置、覆盖已有视频或清理其他下载任务。

原技能证据来自 macOS 操作示范，截止验证点是匹配任务进入准备队列；本包没有验证自动完整下载，也不保证其他系统和宿主具备相同控制能力。
