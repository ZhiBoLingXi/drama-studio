# C2 人物与世界

[工位通用协议](README.md) · 契约 v0.1

| 项 | 内容 |
| --- | --- |
| 必读本剧依据 | 已确认的简报、类型承诺、已确定角色与设定 |
| 主要知识 | K1、K2 人物行为与关系策略、K5 语言与视听表达；没有知识缺口时可以不检索 |
| 产出 | 人物与世界包：欲望／顾虑／策略、关系、能力边界、世界规则及代价、声音探针；已选与待探索分开（kind：`characters`） |
| 交接 | `run-handoff`；问题属于上游时提 `changeProposals`（目标层须在本层之前） |

## 方法要点

- 按“面对谁、争取什么、为什么只能这样争取”组织人物，不按身份贴性格词。
- 为关键关系写声音探针：同一人面对亲人、上位者、对手如何不同。探针是候选，不是已发生的剧情。
- 设定必须产出限制与代价；新增能力不能只增加解题便利。

## 停止与边界

去掉姓名后，仍能从目标、策略与代价区分人物。 返修次数不超过 `task.revisionBudget`；触顶就交付未达标候选并写明瓶颈。
