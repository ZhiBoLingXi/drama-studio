# C4 分集集纲

[工位通用协议](README.md) · 契约 v0.1

| 项 | 内容 |
| --- | --- |
| 必读本剧依据 | 全剧结构、前集实际正文（不是前集计划）、邻集接口、人物近期经历 |
| 主要知识 | K3、K4、K8、K9 修改经验；没有知识缺口时可以不检索 |
| 产出 | 可写的分集纲：处境、行动目标、阻力、关键选择、关系变化、情绪变化依据、出口与待核前提（kind：`episode_outline`） |
| 交接 | `run-handoff`；问题属于上游时提 `changeProposals`（目标层须在本层之前） |

## 方法要点

- 情绪变化必须有可写的选择与经历；“被感动、决定原谅”不能留给正文补黑箱。
- 入口读取前集实际发生的事；前集未写完时用显式计划接口并标“待正文对齐”。
- 按戏剧问题检索，不按“找一场精彩的戏”检索；检查连续几集是否用同一种解法。

## 停止与边界

不设每场反转配额；每场能说明它承担什么变化即可。 返修次数不超过 `task.revisionBudget`；触顶就交付未达标候选并写明瓶颈。
