# C6 审读与整合

[工位通用协议](README.md) · 契约 v0.1

| 项 | 内容 |
| --- | --- |
| 必读本剧依据 | 待审正文与必要前文；第二轮才看目标、状态索引、制作限制与知识依据 |
| 主要知识 | K8、K9 与相应方法和反例；没有知识缺口时可以不检索 |
| 产出 | 审读记录（`review-record`）：事实／目标／偏好分开的问题、文本证据、保留价值、损失、返修归属层（kind：`review`） |
| 交接 | `run-handoff`；问题属于上游时提 `changeProposals`（目标层须在本层之前） |

## 方法要点

- 首读只给观众可获得的信息，用 `reader_effect` 角色装包，不含作者计划与解释。
- 问题回到真正负责的层：台词实现回 C5，关键选择缺失回 C4，人物或主线前提有问题回 C2／C3。
- 保留“原稿更好”“各有损失”“材料不足”“审美分歧”；没有独立上下文时 `context` 如实填 `serial_self_review`。

## 停止与边界

评分不是采用；无硬矛盾不代表本轮修改目标已达成。 返修次数不超过 `task.revisionBudget`；触顶就交付未达标候选并写明瓶颈。
