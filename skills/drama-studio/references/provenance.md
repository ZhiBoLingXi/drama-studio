# 技能来源

本技能来自 Drama Studio 独立仓库，未包含真实项目的剧本、视频或账号。

客观检查工具基于 drama-harness 的确定性工具层（基线 `958547f`），补充严格输入验证、语料不足与重复集号检查。创作方法整理自 DramaRewrite、DramaContinuation、DramaReview 与 topic-craft；下载步骤参考 quark-drama-download，其既有实测边界为 macOS 下载排队。远端状态方法参考 single-drama-adaptation，拉片与正式作品状态仍由 mali-story 提供。

安装包自包含这些方法，不要求安装原个人技能目录。复制或重新打包时保留本页。软件公开授权条款待仓库所有者确定；本页不授予第三方内容或服务使用权限。
