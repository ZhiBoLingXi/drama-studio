# 先验证制作交接，再扩展自动化

适用：既有剧制作停滞，或要把新的创作流程推广给制作团队。不是所有写作任务的必经审批。保留 [两次创作审批](approval-flow.md) 与既有修订授权；不把试点、付费、正式采用混为一项许可。

## 范围与状态

用 [试点交接模板](../templates/production-pilot.md) 保存一个可读包。先选能覆盖不同风险的少量场面：已知失败点及候选修法、合理转移对照、必要上下游。可建议 3–5 集，但不是配额；资产/台词/实际动作复杂度比集数更重要。

AI 可先完成版本与原文对照、纸面动作拆解、未知资源和疑点列表。真实粗搭/导演反馈拿不到时，标 `offline_prepared`；不反复逼问同一缺失项，不代造围读、时长、成本、镜头可用性或人审。只能说“离线准备/演练”，不能说阶段 0 真人验证通过。

真人试点需要实际执行人、范围、版本、日期和失败任务证据。试前约定这次要验证什么、可用时间/资源、继续或收缩的判断依据；未知的数值留空，不启用通用预算。付费试镜必须另有明确执行权限。

先看导演能否定位具体阻断、编剧能否据此修改、修复有没有破坏原有作用，并记录交接/维护工时。多个场面共同适用时才讨论推广。若材料仍不能帮助决定，先改交接或结构，不继续堆模块。没有真人结果不扩展依赖这些结果的全量自动化；已明确且独立的格式缺陷可继续修复验证。

## 疑点不能仅靠状态名过闸

每条疑点先分为核心成立/制作必要条件、普通编辑建议或审美意见，说明影响范围。影响不明或未分流保持待查，不能按“没有确认错误”当通过。

| 情况 | 对本范围的制作建议 |
| --- | --- |
| 核心 confirmed 未修 | blocked |
| 核心 suspected / unresolved、未分流或反证未完成 | needs_evidence，不得 eligible |
| 普通建议/审美分歧 | 保留负责人的取舍，不自动作硬伤 |
| 必要证据齐全且当前有效 | 可提交人工决定，不自动放行或付费 |

“读完全批”不等于“所有疑点处理完”。按类型取证：连续性矛盾查两端/区间/反证；遗漏查义务来源、应发生范围及实际查读；无法拆镜列具体场面、任务与缺失信息；审美保留意见身份。不凑不存在的第二端。

## 防止漏边与旧证据复用

先读原文，再对作者账。重大状态变化不能只沿已登记依赖：检查原文中的实体、别名、事件和远期承诺，写明实际搜索/阅读范围与未覆盖范围。未命中不证明无依赖。

未经过无提示跨批盲测验证时，不声称能够精准缩小所有重核范围；不确定时重核相关阶段和边界，阶段也不明则扩大待核范围。盲测须隐藏缺陷位置与依赖答案，并混入合法转移；主编已读过答案的检查不能冒充盲测。

局部沿用旧结论时，每项要有 evidence_item_id、源/目标修订、范围、依据、依赖检查覆盖、适用性、沿用/重核理由。旧报告整体过期不等于所有条目无用，也不等于可以直接套用。新汇总缺任何必要条目时不称整批有效。

适用性只有 current / stale / unknown；needs_revalidation 是下一动作，不是第四种状态。历史 released 不删除，新稿可以同时显示“历史已批、当前 stale”。

## 共享资源与难镜

资源确认不仅看本批需求，还看同一资源/时间窗的已消耗、已承诺未执行、试制预约及本次新增，明确总容量或剩余容量口径并避免重复扣减。预约用稳定 ID，取消后明确释放。可复用资产按权利和状态判断，不盲目像工日一样扣减。

每次新放行和实际开工前复核易变的档期、素材访问/权利、报价有效期；文件 hash 未变不证明资源还可用。过期/撤回标 stale，缺确认标 unknown。用手工表即可，不借此建设付款或排期系统。

难镜试前约定接受标准、尝试/工时/费用上限、停止条件和推广范围。记录所有尝试及条件、可用数量、总成本、失败原因与条件变化；不同参数条件不能混为同一稳定性样本。一例成功不代表可批量复制；先重估后续资源再决定。不得只报告最终成功截图或把未知尝试次数填 1。

## 当前能力边界

本指南是手工/宿主辅助流程，不是自动门槛引擎。脚本仅验证可客观测量内容；语义审查和真实制作仍分别需要证据。没有新增 workflow-check、远端采用或并发资源预约服务。安装本指南不授权试制、付费、上传或发布。
