# 人物与情绪：从正确解释回到场面

用于已有稿的行为、声音、情绪和戏剧因果修订，也可在首次写作时按需预防。沿用题材、人物关系、审批范围和制作条件，不重走选题，不改已确认结局。不是规定所有故事都含蓄、受创、反转或以家庭和解收尾。

## 1. 把反馈转成本轮可判断的创作目标

先读反馈所指版本和有效前文，再选最影响阅读的少数问题。目标写成“哪一场，读者还没有经历什么”，而不是“情绪增强、人物立体”。例如：一次和解虽说清误会，却没有写出曾经信任的人为什么不敢再伸手，以及对方如何回应。

把问题区分为三类，保存在现有开发或评审记录，不另建一套必填台账：

- **事实与约束问题：**引用冲突两端、义务来源或局部表达缺口；主动找反证，区分已证实、被反证和未知。
- **本轮创作目标缺口：**引用实际行为/台词、必要前文，以及缺失的心理或策略过程；记录达成、未达成或证据不足。它可以阻止宣称本轮修订完成，但不是客观定律、制作禁令或远端采用决定。
- **开放偏好：**存在两种成立的实现时，说明目标读者、取舍与损失，不强求全体评审同意。

“没有事实错误”不能自动关闭创作目标；“我不喜欢”也不能凭空制造目标缺口。用户只查稿则只给诊断和改法，未获改稿授权不写替换正文。

## 2. 从原场面恢复人物，不从形容词重新造人

选择能体现人物常态和受压状态的有效前文，记下：当时想保住什么、惯用什么办法、会回避什么、说话如何因对象而变化。保留少量原文位置作锚，不复制整个人物小传。没有前文时使用已确认人设；推断与新提案另标。

“冷面、善良、聪明”不能决定一场戏。冷面的人可能用命令掩饰担心，也可能用讥讽争回尊严；说短句不自动等于同一个人。角色辨识度来自愿望、关系和策略，口癖与句长只是辅助。

人物可以成长、直说、偶尔做出反常选择。检查的是变化有没有触发、阻力与代价，不把早期语气冻结成永久禁令。儿童按其实际认知与亲历理解事件，不因要表达正确主题而突然替成年人总结全局；儿童主动和聪明也不等于失真。

## 3. 先重建关键选择，再写漂亮台词

对症结场面，比较少量不同的行动办法：人物具体想要什么 → 以自己的习惯尝试 → 对手或现实如何抵抗 → 为何换办法/不换 → 结果怎样改变关系或下一场。只在缺拍处展开，不给每个场面机械加五段。

尤其回查：

- 再次接受危险条件之前，人物上一次受害是否改变了准备和底线？反派要突破防备，需要付出什么？
- 怀疑、识破、原谅、背叛、放弃等转变，有没有角色实际看见/听懂的触发？观众读到的题签不自动成为角色知识。
- “对方失去控制”“退路被封”“证人死亡”等结果，是此前选择的后果，还是只用来把故事送往下一站？缺的是对抗与失败时，不能仅补一句解释。
- 反派输是因为被逼作出代价明确的选择，还是突然坦白、口误、忘记能力？误判可以成立，需要其利益和局势支持，不要求反派永远最优。

例：一个平常用训斥遮掩焦虑的修车师傅发现徒弟要走。泛化的台词“我尊重你的选择，也希望你理解我的担心”可以用于别的人物，但未必适合此刻的他。可试让他先挑徒弟收工具的方法，徒弟把借来的扳手也放下，他才停手：“那把不是借你的。”这不是统一范文；若人物一向坦率、此刻需要明确认错，直接说清可能更有力。

## 4. 台词是在做事，情绪会留下后果

先明确一句话想从谁那里得到什么：试探、隐瞒、逼选、安抚、求助、拒绝、挽留，或别的具体目的。再选说法。不要把所有人都写成同一种成熟的主题解释者，也不要求每句都有潜台词。

写正文前，这一点落在对话表里：每个话题写清说话人此刻想要什么（`speakerWants`）、对方已知什么、关系与情绪，再从处境推出话怎么说（见 [台词层](dialogue-structure.md#3-对话表话题交换listenerknowscarriescloseroneitemperline)）。查稿时按处境对照问：他要的东西要了没有、对方答到点上没有、话的形状像不像此刻那种情绪的人；也可删去主题总结句，看动作是否仍有意义。这些是编辑探针，不是自动合格测试。誓言、揭露、认错、喜剧包袱有时必须直说，删掉反而损伤戏。

沿关键情绪看“触发—尝试/抗拒—选择—余波”有没有真正进入正文。余波可以是一顿吃不下的饭、第二次递手前停住、仍愿留下却不肯回答，不必新添创伤。已经有分饼、避伤、交还物件等有效动作时，优先展开其关系后果，不再追加同义宣言。

跨集或跨批次除道具、伤势、知识外，带入尚未兑现的承诺、信任的损伤及最近选择改变的行为。只记录会影响后续的项，不把每个表情做成状态字段。相邻场面若只是接收新任务，检查是否错过了前场结果真正逼出的决定。

情绪起伏不是每集都哭、每场都冲突。检查一段里的松弛、期待、羞耻、幽默、亲密、愤怒等是否符合题材，是否反复用同一方式兑现。阶段收束和静场可以成立，不强行给它们加袭击或翻盘。

## 5. 用完整样段校准，再按授权扩写

多处存在同类缺陷时，先挑能覆盖主要问题的完整连续样段，必要时另选一个较难的关键选择场面。样段大小由具体问题决定，不默认五集或固定场数。必须说明未改范围与衔接依赖，样段不能冒充全稿。

先比较行动方案，再写完整行动对白；不要先扩一批人设说明、逐句加情绪形容词。样段与旧稿比较后，若用户已授权全稿修订，可继续扩写，无须自行增加人审审批；用户明确要求先看语感，则停在约定样段交付。没有明确收益时按自主迭代的停止条件报告瓶颈，不把较长或较工整当作成功。

审读先看正文与必要前文，再看作者修法说明。比较时允许偏好旧稿、各有得失或两稿都未达目标；指出新稿牺牲的有效动作。已知前次反馈的复审须如实标注，不冒充新冷读。

推荐给审读者的任务：

> 从实际场面说明谁想要什么、用了什么办法、为何改变，以及关系留下了什么后果。分别检查人物声音、关键心理转折、对手策略和跨场因果；列出本轮目标的达成/未达成/证据不足及反证。静场、直说与人物成长不是自动缺陷。把事实错误、创作缺口、开放偏好分开，最后指出最值得保留和仍需重写的场面。不要用作者解释、篇幅、场数或模型高分替代正文。

## 6. 防复发：让实际失败进入后续检验

本轮交付同时回答：正文改了哪些选择，哪项用户意见仍未解决，新稿损失了什么，后续哪些集需要重新读。修改输入后，旧评审不能继续作新稿证明。

技能维护时使用合成或已获使用许可的对照片段：既包括“事实连贯但说教/心理跳步”的缺陷，也包括“安静但关系发生变化”“直白认错有充分前置”“人物合理成长”的反例。不要把私人剧本、固定答案或某一剧的台词塞进分发技能。

实际观察模型如何审、如何改，允许发现新版规则制造了新问题；程序测试只能检查安装、解析和文件契约。一个样段、一次模型复审不能证明今后不再发生。真实编剧对具体正文的反馈继续用于校准，但缺少真人反馈不阻断授权内的写作。
