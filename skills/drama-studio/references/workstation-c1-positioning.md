# C1 创作定位

[工位契约](workstations.md) · 契约 v0.1

| 项 | 内容 |
| --- | --- |
| 必读本剧依据 | 用户要求、用户偏好、用户明确给的制作约束、已有授权；对照作品的已读范围 |
| 主要知识 | K1 生活／职业、K6 类型与市场证据、K8 相似结构；没有知识缺口时可以不检索 |
| 产出 | 选题候选或创作简报：类型承诺、核心矛盾、创作立场、明确限制、独特性依据、未知与不做项。没有页面 semantic，留在本地（`runs/` 下），按 `local_file` 装包 |
| 交接 | `run-handoff`；C1 没有上游工位，`changeProposals` 留空；方向本身有问题时写进 `unfinished` 并请用户决定。C1 不用 `context-pack` 装包时 `contextSnapshotId` 写 `null`，并在 `noSnapshotReason` 写明为什么没有装包 |

## 方法要点

- 先找生活中的张力与受众体验，再看类型惯例；不从“再找三部最像的热剧”起步。
- 删掉某个职业、制度或生活细节，主角是否仍做同样的选择？若是，它只是装饰。
- 候选之间必须能指出不同的冲突来源、关系约束或解决方式；换名字不算差异。

## 停止与边界

选题仍由用户确认；市场表现未知就写未知。修订预算用完后怎么办，见 [修订预算按运行层解释](workstations.md#修订预算按运行层解释)。
