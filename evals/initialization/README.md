# 初始化引导行为验收

两个夹具提供虚构的环境盘点、任务回执和用户回复。测试只允许在临时目录写结果，不操作真实账号、数据库或定时任务。

复跑时为每例建立新目录，将当前技能复制为 `skill/`，将对应 `fixtures/<case>/request.txt` 复制到根目录。新会话只接收技能和请求，不给本页期望或其他会话输出；关闭记忆、不 resume，禁用已有 MCP 启动，限定只读写测试目录。保存输入、技能快照、调用参数、事件、输出和哈希。

| 用例 | 要观察的行为 | 2026-09-24 实际结果 |
| --- | --- | --- |
| opt-out | 不开采集、不追问时间、不要求现在登录；不猜默认集数；分清保存记录与实际部署 | 保留所有用户选择；生成可接续记录，指出工作室路径未提供，未假称在真实目录保存；无采集或任务操作 |
| existing-task | 已有任务改时但当前无操作权限，保留旧绑定，报告期望和实际差异；不要求安装红果 MCP | 记录原任务 hg-daily-17，期望 09:00／实际仍 10:00，沿用 Asia/Shanghai；说明需有权限方原位修改并读回，没有执行修改或立即采集 |

维护者通读两个 result.md 与实际执行事件，均符合本表范围。记录在本地被忽略的 `projects/initialization-eval-20260924/`，含技能快照与哈希。采用本机默认模型与账号，新目录不等于操作系统隔离。其后补充了新会话记录查找及同名文件保护的协议文字，这两个扩展场景未做额外模型实测。

36 项既有标准库测试通过，技能结构与 25 文件分发检查通过。这些检查不证明定时注册、真实触发、暂停效果、上游采集或跨平台支持；后续执行器所需验收见[初始化设计](../../docs/initialization-design.md)。
