# 来源与分发边界

本仓库由既有短剧工作流资产整理为独立安装项目，未复制任何真实剧本、拉片正文、视频、账号信息或用户市场研究快照。

- `scripts/checks/episode_check.py` 与 `dup_check.py` 位于分发技能内，基础实现来自 drama-harness 的确定性工具层（基线 `958547f`）。本仓库补充输入错误、语料不足与重复集号检查。原实现及后续差异在本仓库独立维护。
- 创作参考整合 DramaRewrite 的反同质化、DramaContinuation 的分集创作、DramaReview 的证据定位、topic-craft 的选题研究方法，以自包含参考文档交付，不依赖原作者的个人安装路径。
- 夸克步骤来自 quark-drama-download 的 macOS 示范，原始验证点仅到下载排队，未将其描述为完整自动下载已通过。
- mali-story 的项目接续边界参考 single-drama-adaptation；视频理解与远端正式作品状态仍由 mali-story 提供。本仓库未复制服务端实现或凭据。

软件公开授权条款尚待仓库所有者确定；本文件不额外授予第三方作品或服务的使用权限。复制自本仓库的安装包仍应保留本页来源说明。
