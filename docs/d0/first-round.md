## 首轮创作目标

D2 只针对以下五项；其他方向（市场、选题、全季结构）不在首轮评估范围。

| 目标 | 可观察的正文变化 | 负责工位 |
| --- | --- | --- |
| 人物行动 | 关键处的选择来自人物自己的欲望、顾虑与所知，而不是剧情需要 | C4 选择、C5 实现 |
| 对白语感 | 同一人对不同对象说话方式不同；去掉姓名仍能认出是谁 | C5 |
| 情绪承接 | 情绪变化有可见的经历、反应和后果，不靠旁白或解释 | C4 依据、C5 实现 |
| 集纲因果 | 本集的变化由上一集实际发生的事引出，并留下具体后果 | C4 |
| 结构重复 | 连续几集不反复使用同一种解决办法 | C4、C6 |

**旧稿要保护的价值**：已被用户认可的场面与台词、既有人物关系与声音、确认过的篇幅与制作条件。任何修订都要报告这些方面的损失。
