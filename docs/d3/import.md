## 转换方法

脚本 `projects/yuanxinsuo/tools/docx_to_episodes.py`（项目私有，只用标准库 `zipfile` 与 XML），规则：

1. 按文档顺序读取 `word/document.xml` 的段落，段落文字为其 `w:t` 片段的拼接。
2. 样式 `2`（标题）是分集标题“第N集”；第一个标题是全书题名，其后的副标题“修仙·萌宝团宠｜AI漫剧画面规格｜逐集过硬闸门”不属于任何一集；第 1 集从“场1-1”开始。
3. 样式 `6`（人物动作）在文档中以项目符号“∆”（U+2206）显示，转换为“△”加段落原文（段首空格保留）。这是转换中**唯一**的字符替换。
4. 空段落去掉；标题行不写入正文，集号由 slot 承载；每集正文为其段落按序以换行连接，末尾不加换行。

两次独立运行输出逐字节相同。转换不修改任何原文：已知瑕疵（如第 8 集 8-6 场一句台词被断成两行）原样保留，交给 D3-2（#28）诊断。
