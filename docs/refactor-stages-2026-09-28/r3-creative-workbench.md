# R3：创作上下文与正文工位

设计状态：已拆分待审；实现状态：planned。预计 3–5 个工程工作日。对应 T05、T06。

## 1. 问题与目标

解决“人物小传正确，实际场面却像另一个人”“剧情接上了，情绪没有接上”“对白替作者解释主题”。工程只能保证把哪些版本的材料交给作者，创作方法必须处理材料怎样变成行动、关系和对白。

入口：R1 任务／材料契约，R2 登记与恢复能力，R0 冻结的创作目标。出口：可核验的 ContextPacket、完整候选及简短取舍说明、待复核状态变化。完整候选不是片段集合或加长集纲。

## 2. 上下文的选择与编译

### 2.1 两个职责不能混为一体

- 宿主／创作模型负责提出相关材料及选材理由，识别当前场面的问题。
- 确定性编译器负责读指定版本、验证引用、去除完全重复的引用、保留顺序与分区、标记遗漏和容量；不靠关键词搜索宣布“人物资料已全”。

材料分四区：任务与保护项；有效正文原文；人物／状态索引与推断；作者备选和未采用材料。来源身份不能因被放入上下文而升级。模型使用推断时需说明，不得补造成既有事实。

### 2.2 选材优先级

先放本轮授权、目标、保护项、直接入口和关键知识／能力前提，再放相关人物常态／受压原文、关系余波、必要结尾和季间约束；泛背景摘要最后。用户要求只改七集时，其他集可作只读接口，但不变为可改范围。

容量限制来自实际宿主或既有服务，未知时不伪造精确 token 数。必须材料放不下时缩小本次处理单元或分步阅读，并保存已传范围；不能静默丢失关键前提后仍标包完整。不同页必须属于同一快照。

### 2.3 冲突处置

正文与集纲冲突时，报告两者身份、引用与影响；有效正文不是所有候选的并集。实际人物已成长时不拿最早一集永久冻结语气；也不能为了新场面方便抛弃前文底线。

程序核对引用一致，不能判定哪段具有更高文学价值。重要语义冲突交给主创选择；涉及已批准主线变更则按对应范围确认。

### 2.4 接入既有策划与制作材料

新剧仍沿研究、选题确认、四项送审包、获批后续写的路线；已有稿修订直接恢复对应版本和范围。研究来源与选题理由可追溯，但市场热度不直接变为创作命令。

制作前提保留硬要求、偏好和未知；因果集纲保留人物选择如何改变下一集，而非机械保证每集都有某个钩子词。结构和制作材料由 R1 的专有类型表达，复用已有策划规范，不再造另一套题材研究系统。

## 3. 人物与场面方法

### 3.1 最小人物依据

对本场主要角色保留：当前欲望、怕失去什么、与对手的关系、常用行动方式、回避的表达、眼下已知信息、最近改变行为的经历。每个实质判断附必要原文，未知就保留未知，不要求穷尽人物心理数据库。

对白差异来自对象和目的，不只是句长或口癖。同一人对女儿、敌人、下属应有关系差异；同一人遭遇不同代价也可改变说法。儿童按其设定年龄与亲历表达，不把聪明等同成人总结。

### 3.2 症结场面的开发单元

写前回答：谁要什么 → 先用什么办法 → 遭遇什么抵抗 → 为什么换／不换办法 → 结果如何改变关系或下一场。只针对实际缺拍展开，不把每个场面强制写成五段式。

对高影响症结比较两到三个因果不同的方案：主动行动、对手利益、选择代价、原有亮点损失各是什么。主创作出明确取舍，不能把不同方案的好处全拼在一场里。

### 3.3 台词与情绪落地

先看台词在对谁做什么，再看文采。允许揭露、直接认错、誓言、喜剧包袱；不把“多潜台词”设为唯一风格。遮去姓名是诊断探针，不是自动评分。

情绪进入动作的尝试、抗拒、选择和余波；余波可以是停手、回避、再次伸手前犹豫，也可以是喜悦和松弛。不能为了“情绪强”普遍加创伤、哭喊或袭击。

### 3.4 跨集与跨季

给下一批的不仅是物件、伤势和日期，还包括未兑现承诺、信任损伤、对危险的防备变化、当事人已知与观众已知的差别。只登记会影响后续选择的状态变化，并引用新正文。

状态变化是从正文提取的候选判断，需保存入口、观察到的出口、来源和未决项；新候选不会自动修改正式事实账。实际正文未发生的集纲事件不能登记为已发生。修改前文后生成计划／正文差异和受影响范围，不能只把状态表改到看似一致。

结尾钩子检查其真实引出的下一集问题与下季入口，不能提前消耗第二季关键揭示来获得眼前刺激。结尾承诺与正文选择须能互相解释；省略不是自动错误，也不能靠补旁白解决一切。

## 5. 验收与反例

用原创场景演示：一个惯用命令掩饰关心的人面对亲近者离开。输入包给出他实际如何处理关系的前文，不只写“冷面善良”；产物展示他如何尝试、被拒绝、作选择。审读不要求他永远不能坦白，而要求转变有代价和前置。

反例包括：一场静默但关系改变的饭局；有充分铺垫的直接认错；人物尚未知道的秘密；上集遭背叛后下集仍无防备；修前文却使后文牺牲失去必要性。

本阶段只证明输入和写作过程已接上，质量结论交 R4 真实对照；不能用模板字段齐全宣布戏好看。支持 AC-09、AC-10、AC-17、AC-18。

## 6. 修改边界与回退

方法和模板改动位于自包含技能；程序只编译／核验材料，不增加模型供应商代码。原创评估样本可新增，当前私人剧本只有在相应改稿授权内才修改，不能以系统演练为名扩写。

若新方法造成同质化，保留 R2 版本底座，回退该方法版本，保存失败候选和判断依据；不为通过评估删掉反例。主创对最终选择负责，评审建议不能自动累加改稿。
