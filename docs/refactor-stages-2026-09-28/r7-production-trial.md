# R7：导演试制、有限放行与反馈回流

设计状态：已拆分待审；执行状态：planned／外部条件未具备。对应 T11 的制作证据部分，工期和费用待真实条件明确后单独估算。

## 1. 目标与边界

目标是用少量真实场面回答“这版能否在这些条件下继续制作”，不是借剧本或工具检查证明盈利。导演反馈目前拿不到，本阶段设计可以完成，实际围读、拆镜、试制不能代填。

入口为固定版交付、未决问题、实际授权；材料若仍待创作采用，应明确是用于探索验证的候选，而不是正式投产稿。

## 2. 分两步，避免整个计划一起等待

### 2.1 无需导演结果的离线准备

选场覆盖不同风险而非固定集数配额：关键心理转折、多人调度、物件／能力状态变化、长对白节奏、既有镜头复用。给出原稿／候选及必要上下游，标明哪些只是纸面判断。

每项风险写清实际待验证的问题、输入版本、可接受证据、若失败影响哪些集／资产。保留低风险或合理状态转移作为对照，不把试点设计成只能证实作者方案。

### 2.2 真实试点前的输入

实际导演／制片、候选版本与范围、目标片长或验证区间、可用资产及权利、执行时间、尝试／工时／费用上限、继续或收缩条件。缺失数值留空，不能套通用预算或按字数假装已测时长。

准备试点、人工放行与付费执行分别授权；不以“同意重构”替代任何一项。

## 3. 证据与资源设计

围读／粗剪记录包含版本、人员、日期、计时口径、动作和停顿是否计入，以及实际媒体或可核记录。纸面估算和实测分栏；单集较长不直接推出必须删戏，先定位节奏和功能。

拆镜列出每场任务、角色、地点、道具状态、能力呈现及不可逆动作；同一道具的完好、损坏、替身状态分别考虑。已做过的粗搭必须核对对应正文版本，不能仅凭“前 20 集做过”假定全部可复用。

共享资源记录稳定 ID、口径、有效时间窗、已消耗、已承诺未执行、试制预约和本次新增。可复用资产按权利和版本评估，不把每次引用都重复扣减。此处使用手工记录或现有系统，不建设新的预算／排期平台。

每个难镜记录所有尝试、条件、失败原因、可用结果、总工时和总成本；一次成功不能证明批量可复制。尝试次数未知就未知，不能只保存最好截图或把成本记为零。

如果本批没有需要实际试制的专项风险，由实际负责人确认不适用范围与依据，R7-04 可交“不适用”的证据记录；不为走完流程强造难镜或付费试制。必要项目仍未知时不能用“不适用”跳过，整批制作验证也不能因此被豁免。

## 4. 决定与失效

制作建议维度：核心成立条件已证实不满足则 blocked；必要条件或核心疑点未清则 needs_evidence；必要证据当前有效才 eligible。普通审美意见不自动成为制作硬禁令。

eligible 只是可以提交人工决定。真正放行必须有决定人、版本、范围、条件、资源、有效期和撤回方式；费用许可另记。版本或关键资源变化后复核适用性，历史放行事件保留，新版不能自动继承。

决定可以是仅放行某些场面、先围读不试制、退回结构修改或不采用。完成试点工作不等于得到了正向放行，更不等于利润改善。

## 6. 演示、反例与停止

反例：稿件未变但演员档期取消；资产可访问但使用权已过期；一次难镜成功但尝试成本超限；试制只覆盖一个场面却要求整季放行；导演给出偏好却没有指出制作阻断。这些必须产生不同结论，不能统一变成失败或通过。

试点达到上限、实际条件与约定明显不符或出现无法解释的风险时停止该试验，保留素材与记录。不能在未取得新权限时不断加预算／次数来证明方案成立。

导演一直不可参与时，R7-01 可完成离线准备，R7-02～R7-06 不执行，明确等待的证据及责任方；不反复向用户索取已说明拿不到的材料，也不据此停掉无依赖的工程工作。

回流不得把本剧某个道具／台词细节直接固化成所有题材的硬规则。先形成失效机制和合法反例，经 R4 对照后再决定是否调整方法。未获材料使用许可，不把私人反馈或原稿写进技能分发。
