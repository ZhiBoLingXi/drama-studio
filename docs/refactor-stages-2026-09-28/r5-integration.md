# R5：复用既有能力与远端对账

设计状态：已拆分待审；实现状态：planned。预计 2–4 个工程工作日，不含等待权限或部署。对应 T09。

## 1. 目标与输入

将本地任务、来源、候选和审查与已有 mali-story 能力接起来，而不是另造网络客户端、正式项目库或模型服务。Python 只处理本地契约，实际 MCP／连接器调用由宿主执行。

入口：R1 契约、R2 登记与恢复、R3 上下文包、R0 能力盘点。输出：能力矩阵、输入形态映射、请求／回执关联、对账协议、端到端实测或明确降级。

## 2. 按能力启用，不设全局“已连接”

每项能力记录工具名称／版本（可知部分）、当前宿主、认证主体、绑定项目、发现时间、实测时间、输入形态、权限、副作用、预算要求和限制。

状态分开：源码可见、宿主已发现、身份已验证、业务只读成功、写入回读成功、实际审查成功、费用已对账。每项记录只支持相应声明；doctor 的离线成功不能激活联网功能。

读、保存候选、模型审查、文档上传不是一项权限。实际写入测试要使用获准测试项目；没有授权则只运行模拟／契约测试并保持该功能关闭。

## 3. 三条主要适配路径

### 3.1 上下文

优先使用当前可用的 get_writing_context 读取快照。分页必须锁定同一 inputSnapshotId，来源变化后从头取新快照；不能混合两个版本的页。prepare_story_context 用于显式选择已有候选材料，不负责决定这些候选已采用。

本地 ContextPacket 保存远端快照引用、选材、原始来源新鲜度和本地转换关系。即使选材操作成功，选入候选仍可能来自旧基线；不能把新的包 ID 当作全部来源已刷新。

### 3.2 候选保存与回读

本地 revision 映射到 remote project、slot、artifact、revision、inputSnapshotId。读取真实 schema，不能假设 snake_case 与 camelCase 输入可混用。当前工具从认证会话提供身份时，不自行填 userId 欺骗服务。

写前持久保存 RemoteIntent：操作类型、请求标识、准确内容摘要、目标项目、预期版本、费用／写入授权来源。保存成功后回读实际全文并核对摘要；分页读到终点仅说明读取范围，不说明创作通过。

本地候选不自动写正式块。已采用正文的 episode/rootBlock 审查与显式候选 artifact-review 不是同一输入形态；不适配就使用宿主审读并登记本地报告，不能把候选升格去迎合接口。

### 3.3 审查任务

仅在任务输入、权限、部署及用户选定预算均符合时使用已有持久审查服务。保存 requestId、runId、快照和实际预算回执。既有服务的 claim、resume、cancel、预算和复核规则为权威，不在本地重建一套调度器。

报告拿到之后仍检查目标范围、快照、实际内容、前次未决项和当前来源。远端 completed 不等于创作通过、用户采用或制作放行。

## 4. 未知结果与重试

| 观察 | 行动 | 禁止 |
| --- | --- | --- |
| 意图已保存但尚未调用 | 在原授权仍有效时由宿主发起一次 | 不因 intent 文件存在宣称已经提交 |
| 已调用但响应丢失 | 查询原 request/run/artifact；保持 unknown | 换新 ID 再发同一付费工作 |
| 明确找回同一次不可变保存 | 核对内容、归属和版本后登记回执 | 将不同项目同名候选认作原结果 |
| 服务确认可幂等重放的纯保存 | 按同键同输入重放，保留依据 | 把纯保存的可重放性推广到模型执行 |
| 模型调用 running/unknown | 使用服务已有查询／恢复路径 | 另启任务“试一次看看” |
| 来源已变但结果已存在 | 保留旧候选，标过期并提出重核 | 静默 rebase 旧正文到新快照 |
| 无能力、无权限或费用不可核 | 本地继续可独立工作；列待办 | 报同步、审查或零费用成功 |

## 6. 测试、边界与回退

反例必须包括：同名不同项目、认证已失效、工具同名 schema 改变、分页中来源变化、保存成功却本地超时、收费调用结果未知、返回正文被截断、只有列表元数据没有全文。

本阶段默认不改 mali-story 服务器；如果出现确证的接口缺口，单列窄变更及消费方端到端验收。若涉及持久状态必须沿既有 shared repository；若涉及 DB 只走迁移，不手工 DDL。

测试数据、原始正文与详细回执留在获准项目；公开日志只放必要定位和摘要，去掉令牌、临时签名 URL 和无关个人数据。调试成功也不授权上传真实剧本。

回退逐项关闭联网能力，保留本地候选、原请求和回执以便对账；不能通过删记录消除未知费用。R6 本地版本可以不依赖联网通过，但不得宣传缺失的能力已可用。
